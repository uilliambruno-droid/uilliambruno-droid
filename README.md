## Featured projects

### [Laborit Project](https://github.com/uilliambruno-droid/Laborit-project)
Commercial copilot API built with FastAPI, SQLAlchemy and MySQL. It uses response/data caches, Redis with an in-memory fallback, retry/timeout/circuit-breaker controls, health and metrics endpoints, and per-request execution metadata. The repository README reports 31 passing tests and 99% app-package coverage for its documented run.

### [FastAPI Blog API](https://github.com/uilliambruno-droid/fastapi-blog)
Asynchronous REST API with JWT authentication, owner-based post authorization, admin override, Alembic migrations, request logging and security headers. The repository README reports 37+ unit/integration tests and 99% coverage for its documented run.

### [PropPilot Take-Home](https://github.com/uilliambruno-droid/proppilot-take-home) · [Live demo](https://proppilot-take-home-fawn.vercel.app)
Multi-tenant lead inbox with public agency-specific forms, Supabase authentication, Postgres RLS and realtime updates. The database schema and policies are versioned in the repository. Its README documents manual tenant-isolation checks and notes that there is no end-to-end test suite.

### [Hermes ETL](https://github.com/uilliambruno-droid/hermes-etl)
Luigi pipeline that collects public job listings, normalizes and validates records, filters and deduplicates them, then notifies Telegram about new matches. It writes inspectable CSV/JSON artifacts and supports a mock provider and Telegram dry-run.

### [Fraud Detector](https://github.com/uilliambruno-droid/fraud_detector)
Imbalanced credit-card fraud workflow using stratified data splits, Logistic Regression and XGBoost baselines, cost-based threshold selection and MLflow tracking. Tests are included for data, metrics and modeling.
